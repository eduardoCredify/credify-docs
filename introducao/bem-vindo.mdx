## O que é a Credify API?

A Credify API oferece acesso a dados veiculares, cadastrais, judiciais, antifraude e muito mais — tudo em uma única plataforma integrada.

## Fluxo básico de uso

<Steps>
  <Step title="Autentique-se">
    Chame o endpoint `/auth` com seu `client_id` e `client_secret` para obter o token JWT.
  </Step>
  <Step title="Use o token">
    Inclua o token no header `Authorization: Bearer {token}` em todas as requisições.
  </Step>
  <Step title="Faça as consultas">
    Acesse qualquer endpoint disponível com o token válido. O token expira em 24 horas.
  </Step>
</Steps>
